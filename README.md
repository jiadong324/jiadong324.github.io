# Jiadong Lin — Academic homepage

A responsive academic homepage for [Jiadong Lin](https://github.com/jiadong324), featuring research interests, selected publications, and open-source genomics software.

## Local development

```bash
pnpm install
pnpm dev
```

## Deploy to GitHub Pages

Create a public repository named `jiadong324.github.io`, copy this project into it, and push to the `main` branch. In the repository settings, select **Pages → Source → GitHub Actions**. The included workflow will build and publish the site automatically.

Before publishing, confirm the biography, publication list, email address, and “Open to collaboration” label.
